# OpenRB-150 짐벌 페이로드 — 배선·포트 배정 스펙 (v2, 2026-07-22)

담당: GPS geo 파트 (CYN) · 대상 보드: **OpenRB-150 (SAMD21G18A)**
근거: ROBOTIS OpenRB-150 e-Manual + 보드 variant(핀↔SERCOM 정의).

> **원칙:** 펌웨어가 포트/핀/주소를 확정 → 하드웨어를 여기에 맞춰 배선한다.
> 아래 핀 번호대로 결선하면 `hw_backends.h`가 그대로 동작.

---

## 1. 구체 배선표 (무엇을 → OpenRB 몇 번 핀)

| 연결 대상 | 신호 | **OpenRB 핀** | 포트(SAMD) | 비고 |
|---|---|---|---|---|
| **u-blox GPS** | SDA | **D11** | PA08 | I2C 공유, DDC 주소 0x42 |
|  | SCL | **D12** | PA09 | |
|  | VCC | **3.3V** | — | |
|  | GND | **GND** | — | |
| **BMP390 기압계** | SDA | **D11** | PA08 | I2C 공유(같은 버스) |
|  | SCL | **D12** | PA09 | 주소 0x77(SDO=H)/0x76(SDO=L) |
|  | VCC | **3.3V** / GND | — | |
| **BNO085 IMU** | SDA | **D11** | PA08 | I2C 공유 (기존) |
|  | SCL | **D12** | PA09 | 주소 0x4B |
|  | VCC | **3.3V** / GND | — | |
| **로켓 LoRa 모듈** | 모듈 TX → | **D13** (Serial3 RX) | PB23 | 수신 필수 |
|  | 모듈 RX ← | **D14** (Serial3 TX) | PB22 | 송신 쓸 때만 |
|  | VCC | **3.3V**(또는 별도) / GND | — | ★전력주의(아래) |
| **DYNAMIXEL ×2** | DATA/VDD/GND | **DXL 포트**(4구) | Serial1(내부) | ID1 yaw / ID2 pitch |
| PC/디버그·주입 | USB | **USB-C** | Serial | 115200 |

**핵심:** GPS·기압계·IMU 3종을 **I2C 한 버스(D11/D12)**에 공유(주소 상이 → 충돌 없음).
로켓 LoRa는 **Serial3 = D13(RX)/D14(TX)** — OpenRB variant에 이미 정의돼 SERCOM 수작업 불필요.

## 2. I2C 버스 (D11=SDA / D12=SCL 공유)

```
D11(SDA) ──┬── u-blox GPS  SDA (0x42, DDC)
           ├── BMP390      SDA (0x77)
           └── BNO085      SDA (0x4B)
D12(SCL) ──┴── (셋 다 SCL 공유)
3.3V / GND 공통. 풀업저항은 버스에 1쌍만(모듈 내장 중복 시 하나만 남김).
```
- u-blox는 **DDC(I2C) 출력**이 켜져 있어야 함(기본 on). 꼬였으면 코드의 `CFG-VALSET`로 I2C 출력 활성.
- BMP390 주소는 SDO 핀 스트랩으로 결정(★확인).

## 3. 로켓 LoRa — Serial3 (D13/D14)

```cpp
#define LORA_SERIAL Serial3     // .ino: OpenRB 내장, begin만 하면 됨
LORA_SERIAL.begin(LORA_BAUD);   // setup()
```
- 배선: **LoRa 모듈 TX → OpenRB D13**, (양방향이면) **모듈 RX ← OpenRB D14**, GND 공통.
- 모듈 UART 속도를 `LORA_BAUD`(기본 57600)와 일치.
- ★확인 1가지: 설치된 OpenRB 코어에 `Serial3` 인스턴스 존재. 없으면 BT용 **Serial2**(VIN/DXL 옆 4핀 홀)로 `#define`만 교체.

## 4. 전원 (★설계 주의)

- OpenRB **5V 출력 max 150mA**, **3.3V 출력 max 300mA**(2024 개정). 센서·LoRa 총소모 점검 필수.
  - u-blox ~30mA, BNO085 ~12mA, BMP390 <1mA → 3.3V 300mA 내 OK.
  - **LoRa 송신 순간 전류(모듈에 따라 100mA+)**가 크면 3.3V 레일 부족 가능 → LoRa는 **별도 3.3V 레귤레이터** 권장.
- DYNAMIXEL은 **별도 5V Buck**(XL330=5V, 4S 직결 금지). OpenRB 로직과 서보 전원 분리.

## 5. 라이브러리 (아두이노)
`Dynamixel2Arduino`(기존) · `SparkFun BNO08x`(기존) · **`Adafruit BMP3XX`(신규)** + 의존 `Adafruit BusIO`/`Adafruit Unified Sensor` · `Wire`(내장).

## 6. 빌드·플래시
아두이노 IDE에 OpenRB-150 보드매니저 추가 → 위 라이브러리 설치 → **Verify** → Upload.

## 7. 브링업 순서 (부품 도착 후)
1. **Verify**(컴파일 오류 0) — Serial3 인스턴스만 1회 확인.
2. **I2C 스캔** — 0x42/0x4B/0x77 세 주소 응답 확인.
3. **기압계 0점** — 지상에서 `B`(또는 부팅 자동 50샘플). AGL≈0.
4. **GPS fix** — 실외 fixType 3, 위경도 갱신.
5. **로켓 링크** — 34B 패킷 수신 → `pktAgeMs` 갱신.
6. **모드** — `C`로 COARSE, 데이터 끊고 HOLD 폴백/복귀.
7. **튜닝** — Stage A 부호, `SERVO_LEAD_S` 서보 스텝응답 실측.

## 8. 시리얼 명령 (테스트/주입 — 실백엔드와 동일 경로)
```
M yaw pitch | H | Z | C | T0/T1 | I R/S/J | V R/G | Q w x y z
G iTOW lat7 lon7 alt              (페이로드 GPS 주입)
R iTOW lat7 lon7 altmm vN vE vD   (로켓 패킷 주입)
A aglM                            (기압계 AGL 주입)   ← 신규
B                                 (기압계 발사대 0점) ← 신규
```
